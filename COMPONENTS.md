| `components/EditPencil.tsx` | **The** bare pencil trigger — a glyph beside a piece of text that opens what edits it | Two call sites: the home page's city name ("Click here to change your location") and `/event/[id]`'s **About this event** heading in the organiser view ("Click here to edit the event details"). A *published* event that has genuinely sold nothing still shows its zero: that figure is real. ⚠️ **There is no visibility field and no Public/Private badge on a row** (Gautham, 2026-08-21) — every event the backend serves is public, so the console used to stamp a hardcoded "Public" pill on every single row, and a badge that can only ever say one thing carries no information. **Do not add one back, or a filter, or the invite-only copy, until a real visibility column exists** (`TODO.md` §19.8). `PRICE_FILTERS` / `ROW_SORTS` / `filterAndSortRows` live here beside `CONSOLE_TABS` so the labels and the logic honouring them cannot drift; **undated rows sort to the END in both directions**, because letting a NaN through `a - b` makes the comparator inconsistent and scrambles the whole list rather than just those rows. |

The imported design deducted it from the organiser; that framing was removed on import — **do not put it back.** |
| `lib/use-today.ts` | Today's date + greeting for the console header | `useSyncExternalStore`, **not** `useState`+`useEffect`: the value is browser-only (server and client can straddle midnight or a timezone), and setState-in-effect is a lint error here. `getSnapshot` returns a **frozen** value — it must be referentially stable or React re-renders forever, so a tab left open across noon keeps its greeting. |

### Sharing routes

Both events and communities produce two branded graphics, generated server-side with `next/og`
(no extra dependencies) from the item's own picture:

- **Link unfurl** — `app/<kind>/[id|slug]/opengraph-image.tsx` (1200×630). `layout.tsx` is a server component whose only job is `generateMetadata()`; Next auto-wires the route into `og:image` / `twitter:image`, so the page itself stays a client component.
- **Story card** — `app/<kind>/[id|slug]/story/route.tsx` (1080×1920 PNG), fetched by `lib/share-event.ts` and handed to `navigator.share`.
- Helpers: `lib/event-media.ts`, `lib/event-server.ts`, `lib/community-server.ts`. ⚠️ `event-media.ts` also exports **`HERO_SCRIM`**, the darkening wash over a hero photo — one definition for `/event/[id]`, `/community/[slug]` and the organiser dashboard's panel. It was a private copy in the first two, with a comment asking the next person to keep them in step by hand. **Import it; do not paste a fourth gradient.**
